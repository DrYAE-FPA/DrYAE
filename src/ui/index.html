Extension Chrome

L'extension envoie à DrYAE les téléchargements de Chrome, les vidéos détectées dans tes onglets et les liens magnet. Elle est utile pour les sites qui bloquent le navigateur intégré (connexion Google, vérification « êtes-vous humain »).

  1. Clique sur Ouvrir le dossier de l'extension ci-dessous.
  2. Dans Chrome, ouvre chrome://extensions (bouton ci-dessous, ou colle l'adresse) et active le Mode développeur en haut à droite.
  3. Clique sur Charger l'extension non empaquetée et choisis le dossier Extension Chrome DrYAE.
  4. Épingle l'icône DrYAE dans la barre de Chrome. DrYAE doit être ouvert pour recevoir les téléchargements.
