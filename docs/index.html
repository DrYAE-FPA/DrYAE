Questions fréquentes

FAQ

DrYAE est-il vraiment gratuit ?

Oui : gratuit, sans publicité, sans abonnement et sans compte. C'est un logiciel libre (licence GPL-3.0).

Is DrYAE really free?

Yes: free, no ads, no subscription and no account. It is free software (GPL-3.0 license).

Est-ce que DrYAE ou GitHub récupère mes informations ?

Non. DrYAE ne collecte aucune donnée personnelle et le téléchargement depuis GitHub ne demande rien sur vous. Dans DrYAE, Paramètres → Confidentialité et sécurité liste tout ce qui est envoyé sur internet.

Do DrYAE or GitHub collect my information?

No. DrYAE collects no personal data and downloading from GitHub asks nothing about you. In DrYAE, Settings → Privacy and security lists everything sent online.

Mon ordinateur est modeste, ça marche ?

Oui : DrYAE met en veille les onglets inutilisés et a des économiseurs de mémoire, de batterie et de données.

Will it run on a modest PC?

Yes: DrYAE puts unused tabs to sleep and has memory, battery and data savers.

Où trouver le mode d'emploi complet ?

Dans DrYAE, appuyez sur F1. Il est aussi en ligne.

Where is the full user guide?

In DrYAE, press F1. It is also online.
